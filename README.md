# github-assets

Images referenced from pull request bodies and issues, one folder per pull request (`pr-<number>/`). An orphan branch, so nothing here is ever part of a build, a release or the site.

Screens of the device are captured by `website/bin/screenshots` on the branch under review, and scaled 3x nearest-neighbour: the panel is 200x200 and a 1-bit glyph is unreadable at 1:1 in a review.
